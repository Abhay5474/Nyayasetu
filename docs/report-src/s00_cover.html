System Architecture & Interview Guide

NyayaSetu

An LLM-powered legal and RTI document simplifier for English and Marathi: how the four services fit together, how data flows between them, and how every feature works.
Final-year major project  ·  Report version 1.0  ·  October 2026
Stack: React · Spring Boot · FastAPI · PostgreSQL + pgvector · Docker Compose
Source: github.com/Abhay5474/Nyayasetu (branch claude/modest-brown-996d6q)

What this report is for

It explains the system the way you would explain it in a viva or a technical interview: the problem, the architecture, the reason behind each design decision, the data flow between services, the problems that were hit and fixed, the measured results, and an honest list of limitations. Each major feature ends with likely interview questions and model answers.

1 · FrontendReact 18 SPA behind nginx; English and Marathi UI
2 · BackendSpring Boot gateway: auth, storage, orchestration, alerts
3 · AI serviceFastAPI: OCR, RAG, LLM, chat, draft generator
4 · PostgreSQLApp data plus pgvector knowledge base

How to read the numbers in this report

Figures such as test counts, chunk counts, defaults and evaluation scores come from the code and from runs made during development. Where a figure was measured on real models (the retrieval evaluation) it is labelled. Where something could not be tested here (for example a specific third-party LLM) the report says so.
