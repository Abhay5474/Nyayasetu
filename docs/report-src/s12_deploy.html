12Deployment and operations

12.1 Compose file in plain words

ServiceImage / buildWiring
postgrespgvector/pgvector:pg16Volume pgdata; db/init.sql creates the vector extension on first start; pg_isready health check; the password is required (POSTGRES_PASSWORD).
ai-servicebuild ./ai-service (Python 3.12-slim + Tesseract mar/hin/eng; models baked in)Depends on healthy Postgres; environment for database URL, internal token, LLM provider/model/keys/fallbacks, embedding and reranker models; expose: 8000 only; host.docker.internal mapped so a local Ollama can be reached.
backendbuild ./backend (Maven build stage, JRE 21 runtime)Depends on healthy Postgres and started AI service; JWT secret and internal token required; uploads volume at /data/uploads; alert and mail/SMS settings; expose: 8080.
frontendbuild ./frontend (Node 22 build, nginx runtime)Depends on healthy backend; publishes ${FRONTEND_PORT:-3000}:80.

Start-up order: Postgres becomes healthy → AI service and backend start (the backend runs Flyway migrations) → frontend starts when the backend is healthy. The AI service loads models and the knowledge base in the background; /health reports progress.

12.2 Configuration (twelve-factor)

All settings are environment variables read into typed classes (AppProperties in Java, Settings in Python); .env.example documents them. The ones people change most:

VariableMeaning
POSTGRES_PASSWORD, JWT_SECRET, INTERNAL_TOKENRequired secrets (the stack refuses to start without them).
LLM_PROVIDER, LLM_MODEL, OPENAI_API_KEY, OPENAI_BASE_URL, ANTHROPIC_API_KEYPrimary model; openai works with any OpenAI-compatible endpoint (Groq, Gemini…).
LLM_FALLBACK_MODELS, FALLBACK_LLM_PROVIDER/MODEL/API_KEY/BASE_URLBackup models on the same provider, then a second provider.
EMBEDDING_PROVIDER, RERANKERfastembed/cross-encoder in production; hash/lexical for offline tests.
ALERTS_ENABLED, ALERTS_CRON, MAIL_*, SMS_PROVIDER, TWILIO_*Optional reminder job and channels.
FRONTEND_PORT, CORS_ALLOWED_ORIGINS, MAX_UPLOAD_MBWeb settings.

12.3 Local development without Docker for every service

# database with pgvector (one container, or a local Postgres + CREATE EXTENSION vector)
docker run -d -p 5432:5432 -e POSTGRES_USER=nyayasetu -e POSTGRES_PASSWORD=nyayasetu -e POSTGRES_DB=nyayasetu pgvector/pgvector:pg16
# AI service (needs tesseract-ocr + mar/hin packs)
cd ai-service && pip install -r requirements.txt && INTERNAL_TOKEN=dev uvicorn app.main:app --port 8000
# backend
cd backend && JWT_SECRET=<32+ chars> AI_INTERNAL_TOKEN=dev mvn spring-boot:run
# frontend (proxies /api to :8080)
cd frontend && npm install && npm run dev

12.4 Images, size and rebuilds

  • The AI service image is the largest (several GB): Python packages (ONNX runtime, fastembed, PyMuPDF…) plus about 1 GB of baked models. A complete set of images is roughly 8–10 GB.
  • The Dockerfile installs the ML libraries and downloads the models before the other requirements, so editing requirements.txt or the code does not re-download the models. Without this ordering, each rebuild left a multi-gigabyte unused layer behind (a real disk-space problem on a Windows laptop).
  • Housekeeping: docker image prune and docker builder prune after rebuilds; never docker volume prune (it deletes pgdata). On Windows with WSL2, freed space returns to drive C: only after the Docker disk file is compacted.

12.5 Continuous integration

GitHub Actions runs three jobs on every push: ai-service (installs Tesseract with Marathi/Hindi packs, starts a pgvector Postgres and runs pytest including the real-OCR and real-pgvector tests), backend (mvn verify against Postgres) and frontend (npm ci && npm test && npm run build).

12.6 Observability and diagnostics

  • /actuator/health (backend, including an AI-service indicator) and /health (AI service: database, chunk count, ingestion state, models, LLM chain).
  • docker compose exec ai-service python -m app.llm.check → which models answer; --list-models → names the keys can use.
  • Logs name the failing step and model on every fallback (“LLM openai:… failed (llm_overloaded)”); no secrets are logged.
