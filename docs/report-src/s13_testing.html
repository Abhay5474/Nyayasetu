What the tests deliberately do not prove

The real embedding model, the real reranker and any real LLM cannot be exercised in the CI environment’s offline mode. They were exercised separately: the retrieval evaluation below ran with the real models on a local machine; answer quality with a real LLM was checked by hand on sample documents, not scored.

13.2 Retrieval evaluation: method

  • Question set: 60 questions in ai-service/eval/questions.jsonl: 40 English and 17 Marathi answerable questions across RTI procedure, consumer law and other laws, 12 of them phrased informally (“I filed an RTI and got no reply…”), plus 3 out-of-scope questions (not scored for retrieval).
  • Gold labels: for each question, the knowledge-base provisions that contain the answer, assigned by reading the source text (not by looking at what the retriever returned). A test fails if a label points at a missing or superseded provision.
  • Metrics: Hit@k = a gold provision is among the top k results; MRR = mean of 1/rank of the first gold provision (depth 10); 95% bootstrap confidence interval; and “superseded text returned”.
  • Ablation: each method adds one component to the previous one.

What the results show

  • Each added component helped: MRR 0.559 → 0.589 → 0.648 → 0.702 from vector-only to the full pipeline, and the correct provision was in the top three for 82% of questions with the cross-encoder.
  • Superseded law was never returned by any method (0%).
  • English is stronger than Marathi (full pipeline MRR 0.744 vs 0.605). Several Marathi misses are questions whose answer sits in the noisy scanned Marathi Act.
  • Direct questions beat informal ones (MRR 0.766 vs 0.465).
  • The confidence intervals are wide (about ±0.1) because there are only 57 questions: small differences between neighbouring methods should not be over-interpreted.
The evaluation found a real bug

The keyword-only score (MRR 0.373) was far below what the same keyword code had scored in an earlier offline run (0.695). The cause: the in-memory store weighted terms by rarity, but the Postgres query used ts_rank_cd, which treats “how”, “many” and “days” the same as “poverty” or “penalty”. Reproducing the gap against the local Postgres confirmed it, and the fix (IDF-weighted scoring, section 7.3) raised keyword-only MRR from 0.373 to 0.661 and hybrid from 0.480 to 0.594 in the offline-embedder run. The fixed system has not yet been re-measured with the real models, so the table above shows the before-fix numbers for the keyword and hybrid rows.

13.4 Answer-quality evaluation (built, partly run)

The harness also scores answers from a real LLM: required facts present (fact recall), whether a relevant provision was cited (citation hit and precision), whether every number in the answer appears in the cited text, and whether out-of-scope questions are declined. The scoring logic is unit-tested with a stub model. It was not run at scale against a real LLM for this report, so no answer-quality numbers are claimed. The string checks flag likely errors but cannot prove an answer correct; a human reviewer should read a sample.

13.5 Other measurements

  • OCR: 98–100% word recall on three synthetic noisy phone-photo images (English and Marathi).
  • Draft PDFs: Marathi PDF shaping verified by rendering the PDF to an image and OCR-ing it with the Marathi model, plus visual inspection.
How do you know your RAG pipeline works?

I measured it. I wrote 57 scored questions with gold provisions, compared five retrieval methods with confidence intervals, and found that hybrid plus a cross-encoder reranker reached MRR 0.70 and top-3 hit rate 82%, with zero superseded results. The evaluation also exposed a defect in my keyword ranking, which I then fixed and added a regression test for. I am explicit about the limits: a small set, labels I assigned myself, and answer quality not yet scored at scale.

Why MRR and Hit@k rather than accuracy?

Retrieval returns a ranked list, and what matters downstream is whether the right provision is near the top, because only the top few sources go into the LLM prompt. Hit@k answers “is it in the prompt?”, MRR rewards ranking it higher.
