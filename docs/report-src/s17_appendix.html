A.2 Glossary

TermMeaning
RTIRight to Information Act, 2005: citizens may request information from public authorities.
PIO / SPIO / CPIO(State / Central) Public Information Officer: the officer who answers RTI applications.
First Appellate AuthoritySenior officer in the same authority who hears the first appeal (Section 19(1)).
Information CommissionCentral or State body for second appeals and complaints; the only body that can impose the Section 20 penalty.
Deemed refusalNo reply within the time limit is treated as a refusal (Section 7(2)).
Section 8 / 9 / 10Exemptions from disclosure · grounds of copyright · severability (release the non-exempt part).
SupersededReplaced by a later rule or notification. Kept for history, excluded from retrieval.
GazetteThe government’s official publication of Acts, Rules and notifications.
RAGRetrieval-augmented generation: retrieve relevant text, then let the model answer using it.
EmbeddingA vector representing the meaning of a text; similar meanings give nearby vectors.
HNSWHierarchical Navigable Small World: an approximate nearest-neighbour index used by pgvector.
RRFReciprocal Rank Fusion: merge ranked lists by summing 1/(k + rank).
Cross-encoderA model that scores a (query, passage) pair jointly; used to rerank.
IDFInverse document frequency: weights rare words more than common ones.
MRR / Hit@kMean reciprocal rank of the first correct result · share of questions with a correct result in the top k.
JWTJSON Web Token: a signed token carrying the user’s identity.
FlywayDatabase migration tool that applies versioned SQL scripts.
OCROptical character recognition: turning an image of text into text.

A.3 Useful commands

docker compose up -d                                   # start (add --build only when code changed)
docker compose up -d --build ai-service                # rebuild one service
docker compose exec ai-service python -m app.llm.check               # which LLMs answer
docker compose exec ai-service python -m app.llm.check --list-models # model names the keys can use
docker compose exec ai-service python -m app.evaluation retrieval    # retrieval evaluation
docker compose logs --tail 50 ai-service               # recent AI-service logs
docker image prune -f && docker builder prune -f       # reclaim disk (never prune volumes)
# tests
cd ai-service && TEST_DATABASE_URL=postgresql://… pytest -q
cd backend    && TEST_DB_URL=jdbc:postgresql://localhost:5432/nyayasetu_test mvn test
cd frontend   && npm test
