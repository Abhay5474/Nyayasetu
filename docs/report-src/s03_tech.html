LayerChoiceWhy this and not the alternative
UIReact 18, Vite 5, Tailwind CSS 3, Axios, react-router, lucide-reactComponent model suits a stateful results page and chat; Vite gives fast builds; Tailwind keeps styling consistent without a design system; Axios interceptors centralise the auth header and 401 handling.
Web servernginx 1.27 (alpine)Serves static files efficiently, adds security headers/CSP, and proxies /api so the browser sees one origin (no CORS in production).
GatewaySpring Boot 3.3.5, Java 21, Spring Security, Spring Data JPA, Flyway, jjwt 0.12.6, BCrypt(12), RestClientMature security and transaction model; Flyway gives versioned schema migrations; RestClient is the modern synchronous HTTP client.
AI serviceFastAPI + uvicorn, Pydantic v2, LangChain core, PyMuPDF, Tesseract (mar+hin+eng), fastembed (ONNX), psycopg 3 + pgvector, python-docxPydantic gives strict, self-documenting JSON contracts; PyMuPDF is fast and also renders the draft PDFs; Tesseract has Marathi/Hindi models; fastembed runs multilingual embeddings and a cross-encoder without PyTorch (smaller image).
DatabasePostgreSQL 16 with pgvectorOne database for relational data, full-text search and vectors; avoids running a separate vector database; transactional and easy to back up.
Embeddingsparaphrase-multilingual-MiniLM-L12-v2 (384 dimensions)Small, CPU-friendly, covers English/Hindi/Marathi well enough for retrieval.
Rerankerjina-reranker-v2-base-multilingual cross-encoder (lexical fallback)A cross-encoder reads query and passage together and corrects the first-stage ranking; it was the largest single gain in the evaluation.
LLM accessLangChain chat models: Anthropic, OpenAI-compatible (Groq, Gemini, xAI…), Ollama, plus a mockProvider-agnostic: any OpenAI-compatible endpoint works by changing a URL and key. A fallback chain protects against outages.
PackagingDocker Compose, GitHub Actions CIReproducible start-up and automated tests for all three code bases.
Interview question this answers

“Why not do everything in one Python app?” It would be shorter, yes. The split shows a real service boundary: the identity, storage and transaction logic lives in the stack built for it, while the AI-specific work is isolated behind a narrow, token-protected API. It also let the gateway degrade gracefully when the AI side is slow or down.
