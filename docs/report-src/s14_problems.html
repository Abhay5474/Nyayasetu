14Problems faced and how they were solved

Interviewers like specific stories. Each row is a real problem from the build: symptom, root cause, fix and lesson.

ProblemRoot causeFixLesson
Backend refused to start: “non-empty schema public”The AI service created kb_chunks in public before Flyway’s first run.Knowledge base moved to its own kb schema.Give each service its own schema; start-up order must not matter.
Uploads from the backend corrupted at the AI serviceThe JDK HTTP client attempted an HTTP/2 cleartext upgrade that uvicorn mishandled for multipart bodies.Force HTTP/1.1 in the client.Protocol negotiation can break “working” requests.
Browser POSTs got 403The proxy rewrote Host, so Origin and Host differed and Spring’s CORS check failed.nginx proxy_set_header Host $http_host; Vite changeOrigin: false.Same-origin design is simpler than CORS configuration.
Marathi gazette text unreadable though PDFs looked fineA broken text layer (doubled vowel signs).looks_garbled() → OCR fallback per page.“Has text” does not mean “has good text”.
Wrong rule numbers from OCR (“११९.” instead of “११.”)OCR digit confusion in Devanagari.Reviewable extracted text files, hand corrections, sequential-number parsing, expected-count checks.Put a human-checkable step between OCR and the database.
Fees quoted wrongly (₹30 vs ₹10)Two notifications in one month; the older was loaded as current.Status field and supersession chain; retrieval excludes superseded text; a test pins the current fees.Law has versions; model them.
Citations to non-existent sourcesLLMs can cite ids that were never provided.Grounding pass drops unknown source ids; chat quotes are verified against the document.Validate model output; do not trust it.
Python \w broke Marathi wordsDevanagari vowel signs are not word characters in Python’s regex.Custom tokenizer that keeps matras; language detection by script ratio.Test with the real script, not just Latin text.
LLM calls failing: 401, 404, 503 “high demand”Wrong key type, retired model name, overloaded provider.Coded error messages, key cleaning, fallback chain, llm.check and --list-models.Treat the LLM as an unreliable dependency; design for failure and diagnosability.
Keyword search weaker on Postgres than in memoryts_rank_cd ignores term rarity.IDF-weighted scoring from ts_stat; regression test.Measure; the evaluation caught what unit tests could not.
Drafts failed with a long list of errorsFramework no longer honoured the discriminated union; date check lacked time-zone slack; day/month confusion in date input.Model chosen by kind; one-day tolerance; future dates blocked; chosen date spelled out; field labels in errors.Test the whole path through the UI, including submission.
Docker disk usage grew 8–10 GB per runModel download layer invalidated whenever requirements.txt changed.Reordered Dockerfile layers; documented pruning.Order layers from least to most frequently changed.
“No default constructor” for a security beanTwo constructors (one for tests) and no @Autowired marker.Annotate the public constructor.Testability hooks can change how the framework wires beans.
